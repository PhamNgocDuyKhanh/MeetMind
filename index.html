Settings

Keys are stored only in this browser's local storage and are sent directly to Google / Groq when you use the app — never to any server of ours (there isn't one). Your live transcript and any AI summary are also kept in this browser's local storage while a meeting is running, purely so a reload doesn't lose your work — that data is cleared as soon as you start a new meeting, or you can clear it yourself below. Anyone with access to this browser profile could read any of this, so use keys (and discuss meetings) you're comfortable keeping client-side.

Fetched live from Google's model list. If the fetch fails, type a model name above — it takes precedence over the dropdown. Rate-limit fallback tries a lighter model on this list before switching keys.

Used only when both Gemini keys are exhausted or rate-limited.

Real device names appear here only after the browser has been granted microphone access at least once — start a meeting, then reopen Settings.

Browsers don't let a page choose which device speech recognition listens to — it always uses whatever the OS hands it. For this channel to pick up remote participants, route your meeting audio to a virtual loopback input (e.g. BlackHole on macOS, VB-Audio Cable on Windows) before starting, so recognition can hear it.

Stored data

Clearing keys removes them from this browser only. Clearing recovery data removes the locally-saved transcript/summary used to recover from an accidental reload. Neither affects your other settings.
